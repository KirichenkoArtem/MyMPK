# Мой МпК

## О проекте
Учебный проект первого курса по предмету «Индивидуальный проект».
Приложение помогает студентам быстро получать расписание и хранить заметки к парам.

## Источник расписания:
***[timetable.magtu.ru](https://timetable.magtu.ru/)***

## Что реализовано:
- [x] 1. Просмотр расписание на ближайший день.
- [x] 2. Просмотр расписания на 2 недели (чётная или нечётная).
- [x] 3. Написание/редактирование/удаление заметок к предметам.
- [x] 4. Красивый, интуитивно понятный интерфейс.

## Что можно реализовать:
- [ ] Карту корпусов МпК.
- [ ] Поиск аудитории по карте корпусов.

## Стек:
— **Язык:** *Java*
— **Среда:** *Android Studio*
— **Min Sdk:** *29*

## Зависимости:
— ***org.jsoup:jsoup:1.17.2***

## Как запустить:
1. Клонировать репозиторий.
2. Открыть через Android Studio.
3. Вуаля.
